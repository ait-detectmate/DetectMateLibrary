# What is DetectMate?

Welcome to the documentation for the DetectMate Library. DetectMate is a library for anomaly detection in log data.
It is built from ready-made building blocks (parsers, detectors and aggregators) that you combine into a detection pipeline.

## Why use DetectMate?

* **Stream-friendly:** components process logs as they arrive, so DetectMate
  works for online, real-time anomaly detection, not just offline batch runs.
* **A broad catalogue out of the box:** 6 parsers and 13 detectors
  ship ready to use, from simple rule-based checks to deep-learning sequence models.
* **Need something specific to your data?** Inherit from the respective core class to build a parser or detector for your own use case. The core classes provide all the essentials, so creating a fully custom component for your use case takes very little code.
